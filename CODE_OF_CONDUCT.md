# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## En resumen

- Tratá a todas las personas con respeto, sin importar su experiencia, identidad u origen.
- Criticá ideas y código, no personas.
- No se toleran acoso, insultos ni ataques personales.

## Cómo reportar

Si ves un comportamiento inaceptable, contactá al mantenedor ([@Leoglez10](https://github.com/Leoglez10)) por GitHub o usá la opción **Report content** de GitHub en el comentario o issue. Los reportes se revisan de forma confidencial.

El mantenedor puede editar o eliminar comentarios, commits o issues que no respeten este código, y bloquear a quien lo incumpla de forma repetida.
